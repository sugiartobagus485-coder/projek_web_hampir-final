❓ Cara Beli

Ikuti langkah mudah ini untuk mendapatkan kode / source code pilihanmu.

🛍️ Lihat Katalog
1

Pilih Produk

Buka Katalog, pilih kategori, lalu klik produk untuk melihat detail lengkapnya.

2

Tambah ke Keranjang

Klik tombol "+ Keranjang" pada produk yang kamu mau. Bisa pilih lebih dari satu produk.

3

Checkout

Buka Keranjang, isi nama dan nomor WhatsApp, lalu klik "Buat Pesanan".

4

Chat Admin via WhatsApp

Setelah pesanan dibuat, klik tombol "Kirim Pesanan ke WhatsApp Admin" untuk konfirmasi dan pembayaran.

5

Terima File

Admin akan mengirim file source code lewat WhatsApp atau Email setelah pembayaran dikonfirmasi.

⭐

Butuh Bantuan?

Kalau ada kendala, hubungi admin lewat WhatsApp di halaman Profil atau langsung chat dari halaman katalog.

💡 Cara Pembayaran

Pembayaran dilakukan langsung kepada admin setelah kamu mengirim pesanan. Admin akan memberikan nomor rekening / e-wallet dan mengirim file setelah pembayaran masuk.
